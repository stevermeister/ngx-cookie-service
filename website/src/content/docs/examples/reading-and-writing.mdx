## Notes

- `get()` returns `''` for a missing cookie. Use `check()` when an empty value and a missing cookie mean different things.
- `getAll()` decodes names and values. When several cookies share a name (for example with different paths), it keeps the one the browser lists first, the same one `get()` returns.
- Cookies are shared by every tab and every page on the same site and path, so cookies set by other examples on this site show up here too.
