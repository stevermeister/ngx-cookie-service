```ts
import { inject } from '@angular/core';
import { CookieService } from 'ngx-cookie-service';

const cookieService = inject(CookieService);

cookieService.set('theme', 'dark', { expires: 30, path: '/' });
cookieService.get('theme'); // 'dark'
cookieService.delete('theme', { path: '/' });
```

## Why ngx-cookie-service

<CardGrid>
  <Card title="Small and focused" icon="rocket">
    One injectable service, about 1.3 kB minified and gzipped. No dependencies besides Angular.
  </Card>
  <Card title="Server-side rendering" icon="laptop">
    `ngx-cookie-service-ssr` reads the request's cookies and writes `Set-Cookie` headers while Angular renders on the server.
  </Card>
  <Card title="Safe defaults" icon="approve-check">
    `SameSite=Lax` by default, `Secure` forced where browsers require it, and unsafe paths or domains rejected with a warning.
  </Card>
  <Card title="App-wide configuration" icon="setting">
    Set default options once with `provideCookieOptions()`, and choose how values are encoded with `provideCookieEncoding()`.
  </Card>
</CardGrid>
