The major version of ngx-cookie-service matches the major version of Angular. We follow Angular's [support policy](https://angular.dev/reference/versions#actively-supported-versions): the latest release supports **Angular 22**. Angular 14 and older are not supported.

| Angular | ngx-cookie-service / ngx-cookie-service-ssr |
| ------- | ------------------------------------------- |
| 22.x    | 22.x                                        |
| 21.x    | 21.x                                        |
| 20.x    | 20.x                                        |
| 19.x    | 19.x                                        |
| 18.x    | 18.x                                        |
| 17.x    | 17.x                                        |
| 16.x    | 16.x                                        |
| 15.x    | 15.x                                        |

Release notes for every version are in the [changelog](https://github.com/stevermeister/ngx-cookie-service/blob/master/CHANGELOG.md) and on [GitHub releases](https://github.com/stevermeister/ngx-cookie-service/releases).
