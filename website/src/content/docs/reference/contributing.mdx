## Opening issues

Check the [FAQ](/reference/faq/) and the [existing issues](https://github.com/stevermeister/ngx-cookie-service/issues?q=is%3Aissue) first. When you open a new one, include your Angular and ngx-cookie-service versions and, ideally, a small reproduction.

## Pull requests

Pull requests and test cases for things that don't work are welcome. We accept pull requests that pass all checks and add tests where it makes sense. See [CONTRIBUTING.md](https://github.com/stevermeister/ngx-cookie-service/blob/master/CONTRIBUTING.md) for the workflow.

This documentation site lives in the [`website/`](https://github.com/stevermeister/ngx-cookie-service/tree/master/website) folder. Run it locally with:

```bash
pnpm install
pnpm docs:dev
```

Every page has an **Edit page** link at the bottom.

## Author

ngx-cookie-service was created by [7leads GmbH](http://www.7leads.org/) for one of their apps, because the other cookie packages they found were either not designed "the Angular way" or caused trouble with AOT compilation.
